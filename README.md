A single original one-line roast of my fridge, written to `/output/entry.txt`
by `main.ts` (Node 22+).

## The entry

> My fridge hums all night like it pays rent, yet the only thing it ever keeps fresh is the smell of leftovers I swore I'd eat tomorrow.

134 characters, one line, nothing else.

## Run it

```sh
node main.ts
```

It validates the line against the gate (1–200 characters, single line, not
only white space), creates `/output` if needed, and writes
`/output/entry.txt`.
